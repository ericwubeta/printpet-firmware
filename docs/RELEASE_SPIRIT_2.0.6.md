# PrintPet Spirit 2.0.6

相较于 2.0.3，本版新增独立的「外挂耗材」页，X2D 接着 AMS 时也能分别查看。云端重连时保留上次读取的料名与颜色。收到新状态后会自动刷新。本版还修复了读取云状态时因内存不足导致的断连。

下载 `PrintPet-Spirit-2.0.6-install-recovery.zip`，解压后先运行包内离线校验，再按现有引导和分区选择安装或升级。 [安装与恢复说明](https://github.com/ericwubeta/printpet-firmware/blob/v2.0.6/docs/INSTALL.md)

本包使用已在一台设备上实测的同一份应用，原有配置和原厂身份数据在该次应用升级的回读中保持一致。X2D 外挂夜光料正常显示，连云后观察 5 分 12 秒，未复现掉线或内存分配错误。完整 ZIP 通过离线与安装流程模拟检查。 [对应源码与许可](https://github.com/ericwubeta/printpet-firmware/tree/v2.0.6)
