# PrintPet Core 1.6.2

相较于 1.6.1，本版新增独立的「外挂耗材」页。X2D 接着 AMS 时也能分别看两边的耗材。局域网相机预览减少了重复读取，并在 USB 预览期间降低 Wi-Fi 接收延迟。

下载 `PrintPet-Core-1.6.2-install-recovery.zip`，解压后先运行包内离线校验，再按实际分区和引导选择安装或升级。 [安装与恢复说明](https://github.com/ericwubeta/printpet-firmware/blob/v1.6.2/docs/INSTALL.md)

正式包与 Core 1.6.2 社区包使用同一份应用。相机改动的同代码开发构建在一台 X2D 打印时观察了约 96 秒，收到了 71 帧不同画面。正式版应用和完整安装包通过离线校验与模拟检查，完整 ZIP 安装未另行实机刷写。 [对应源码与许可](https://github.com/ericwubeta/printpet-firmware/tree/v1.6.2)
