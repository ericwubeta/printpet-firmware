# PrintPet Core 1.6.1 修复候选

此版本为本地修复和实机稳定性验证候选，尚未新建公开Release。

- 同名Wi-Fi有多个Mesh/扩展器接入点时，先完成全信道扫描，再优先连接信号更强的接入点。此前默认快速扫描可能遇到第一个同名弱节点即停止。
- 开机、自动重连、手动切网、配网页加入网络和APSTA复用已存网络采用同一策略。
- 增加Wi-Fi断开原因码、信号及信道日志，便于区分无线断链与云端连接中断；不增加密码/Token输出。

只读监控、相机与页面记忆、30秒息屏/按键唤醒、原有Wi-Fi modem sleep和电池深睡策略保持原样。此包不包含临时网络诊断任务、SDK Debug日志或故障注入。

沿用Core 1.6.0完整包的保护布局，应用仍为0x370000；历史版本和Spirit发布不改写。已装同一保护布局的设备使用guarded upgrade即可，旧布局仍按INSTALL.md使用完整迁移。不得全片擦除或写入0x310000–0x36FFFF保护区。

本次验证以打印机离线、USB供电的空闲监控为范围；相机负载和真实打印状态仍需打印机可用后另测。具体持续时间、重连次数与验证结果以本轮设备记录为准。
